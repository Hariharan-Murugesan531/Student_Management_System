# 🎓 Student Management System (Java + JDBC+ MySQL)

## 📌 Description
A console-based application to manage student records using Java, JDBC, and MySQL.

## 🚀 Features
- Add Student
- View All Students
- Search by Name
- Update Student
- Delete Student

## 🛠 Tech Stack
- Java
- JDBC
- MySQL

## 📂 Project Structure
- model → Student class
- dao → Database operations
- db → Connection setup
- main → User interface

## ▶️ How to Run
1. Add MySQL Connector JAR
2. Update DB credentials in DBConnection.java
3. Run Main.java
